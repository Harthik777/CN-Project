# Evaluation Evidence

- `metrics_results.json`: untouched-test metrics and operating points.
- `cross_seed_stability.json`: frozen seed-42 bundle evaluated on five unseen
  same-generator seeds.
- `real_data_probe.json`: chronological SPEDIA negative-control probe.
- `run_manifest.json`: source/artifact hashes and dependency versions.
- `figures/`: architecture, curves, per-channel results, classification,
  calibration, confusion matrix, and drift evidence.

The technical report is the authoritative narrative for assumptions,
limitations, and metric interpretation.
